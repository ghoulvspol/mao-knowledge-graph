# 持久战

## 定义与起源

《论持久战》写于1938年5月，是毛泽东在抗日战争全面爆发十个月后撰写的军事战略论著。当时，国内弥漫着两种错误论调："亡国论"认为中国必败，"速胜论"认为可以很快打败日本。毛泽东运用唯物辩证法，分析了中日双方的基本特点——敌强我弱、敌小我大、敌退步我进步、敌寡助我多助，得出"抗日战争是持久战，最后胜利是中国的"这一科学结论。

## 核心要义

### 1. 中日双方的基本特点决定了持久战
> "中日战争不是任何别的战争，乃是半殖民地半封建的中国和帝国主义的日本之间在二十世纪三十年代进行的一个决死的战争。"

中日之间存在四对基本矛盾：敌强我弱、敌小我大、敌退步我进步、敌寡助我多助。这些矛盾决定了中国不会亡国，但也不能速胜，必须打持久战。

### 2. 抗日战争的三个阶段
> "第一个阶段，是敌之战略进攻、我之战略防御的时期。第二个阶段，是敌之战略保守、我之准备反攻的时期。第三个阶段，是我之战略反攻、敌之战略退却的时期。"

第一阶段是战略防御阶段，第二阶段是战略相持阶段（这是最关键的阶段），第三阶段是战略反攻阶段。整个过程体现了量变到质变的辩证法。

### 3. 战争的决定因素是人不是物
> "武器是战争的重要的因素，但不是决定的因素，决定的因素是人不是物。"

战争的伟力之最深厚的根源，存在于民众之中。动员了全国的老百姓，就造成了陷敌于灭顶之灾的汪洋大海。

### 4. 运动战为主，游击战为辅
> "我们的战略方针，应该是使用我们的主力在很长的变动不定的战线上作战。"

在持久战的不同阶段，采取不同的作战形式：防御阶段以运动战为主，游击战为辅；相持阶段以游击战为主，运动战为辅；反攻阶段以运动战为主。

### 5. 主动性、灵活性、计划性
> "主动权不是任何天才家所固有的，只是聪明的领导者从虚心研究和正确地估计客观情况，正确地处置军事政治行动所产生的东西。"

在持久战中必须掌握战争的主动性，灵活运用战略战术，有计划地组织每一次战役。

## 实战案例

- **抗日战争全过程**：1937-1945年的抗日战争基本按照毛泽东预判的三个阶段发展，验证了持久战理论的科学性。
- **百团大战（1940）**：在战略相持阶段，八路军发动大规模游击战，打击日军交通线，体现了相持阶段以游击战为主的方针。
- **敌后根据地建设**：在持久战思想指导下，建立广泛的敌后抗日根据地，形成对日占区的战略包围。

## 思想演变

| 时期 | 特征 |
|------|------|
| 抗战初期（1937） | 写成《抗日游击战争的战略问题》 |
| 形成期（1938） | 写成《论持久战》，系统阐述持久战理论 |
| 相持阶段（1939-1943） | 在实践中不断丰富和发展持久战思想 |
| 反攻阶段（1944-1945） | 持久战理论得到完全验证 |
