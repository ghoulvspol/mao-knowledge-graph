# 新民主主义论

## 定义与起源

《新民主主义论》发表于1940年1月，是毛泽东在中国革命的关键时期撰写的重要政治论著。当时，抗日战争进入相持阶段，国内各派对中国向何处去的问题争论不休。顽固派鼓吹"一个主义、一个政党"，企图消灭共产党和马克思主义；党内也存在"一次革命论"和"二次革命论"的错误倾向。毛泽东在此文中系统阐述了中国革命的性质、对象、任务、动力和前途，提出中国革命必须分两步走：第一步是新民主主义革命，第二步是社会主义革命。

## 核心要义

### 1. 中国革命的性质是新民主主义革命
> "中国革命的历史进程，必须分为两步，其第一步是民主主义的革命，其第二步是社会主义的革命，这是性质不同的两个革命过程。"

中国革命不是旧式的资产阶级民主革命，而是新式的、特殊的民主主义革命，即新民主主义革命。它是无产阶级领导的、人民大众的、反对帝国主义、封建主义和官僚资本主义的革命。

### 2. 革命分两步走
> "民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势。"

第一步是新民主主义革命，第二步是社会主义革命。两个阶段既相互区别又相互衔接，不能"毕其功于一役"，也不能在两个阶段之间横插一个资产阶级专政。

### 3. 无产阶级领导权
> "在今日，谁能领导人民驱逐日本帝国主义，并实施民主政治，谁就是人民的救星。"

新民主主义革命的核心特征是无产阶级（通过共产党）的领导权。这是新民主主义革命区别于旧民主主义革命的根本标志。

### 4. 新民主主义的政治、经济、文化纲领
> "新民主主义的政治、新民主主义的经济和新民主主义的文化相结合，这就是新民主主义共和国。"

政治上：各革命阶级联合专政。经济上：大银行、大工业、大商业归国家所有，没收地主土地分配给农民，允许民族资本主义发展。文化上：民族的、科学的、大众的文化。

### 5. 革命前途是社会主义
> "中国革命的终极的前途，不是资本主义的，而是社会主义和共产主义的。"

新民主主义革命虽然在性质上仍属于资产阶级民主革命的范畴，但它的前途不是资本主义，而是社会主义。

## 实战案例

- **抗日根据地的政权建设**：在陕甘宁边区等抗日根据地实行"三三制"政权（共产党员、非党左派进步分子、中间派各占三分之一），体现了新民主主义的政治纲领。
- **土地改革运动**：实行"耕者有其田"的政策，没收地主土地分配给农民，体现了新民主主义的经济纲领。
- **《论联合政府》（1945）**：在七大报告中进一步发展了新民主主义理论，提出建立民主联合政府的具体方案。

## 思想演变

| 时期 | 特征 |
|------|------|
| 萌芽期（1925-1927） | 《中国社会各阶级的分析》《湖南农民运动考察报告》奠定阶级分析基础 |
| 形成期（1939-1940） | 发表《中国革命和中国共产党》《新民主主义论》，系统阐述理论 |
| 发展期（1945） | 《论联合政府》进一步丰富和发展 |
| 实施期（1949） | 《论人民民主专政》指导新中国建国方案 |

## 原话精选

1. "中国革命必须分为两步，其第一步是民主主义的革命，其第二步是社会主义的革命。"
2. "民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势。"
3. "所谓新民主主义的革命，就是在无产阶级领导之下的人民大众的反帝反封建的革命。"
4. "在今日，谁能领导人民驱逐日本帝国主义，并实施民主政治，谁就是人民的救星。"
5. "新民主主义的政治、新民主主义的经济和新民主主义的文化相结合，这就是新民主主义共和国。"
