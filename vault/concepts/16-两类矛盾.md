# 两类矛盾

## 定义与起源

"两类矛盾"理论是毛泽东在1957年2月发表的《关于正确处理人民内部矛盾的问题》中系统阐述的。社会主义改造完成后，中国进入了社会主义社会，但社会矛盾并没有消失。毛泽东创造性地提出，社会主义社会存在着两类不同性质的矛盾——敌我矛盾和人民内部矛盾，并指出必须用不同的方法处理这两类矛盾。这是对马克思主义矛盾学说的重大发展。

## 核心要义

### 1. 两类矛盾的性质不同
> "在我们的面前有两类社会矛盾，这就是敌我之间的矛盾和人民内部的矛盾。这是性质完全不同的两类矛盾。"

敌我矛盾是对抗性的矛盾，人民内部矛盾是非对抗性的矛盾。两类矛盾的性质不同，解决的方法也不同。

### 2. 敌我矛盾用专政的方法解决
> "敌我之间的矛盾是对抗性的矛盾。人民内部的矛盾，在劳动人民之间说来，是非对抗性的。"

对敌我矛盾，必须用专政的方法，即强制的方法来解决。对人民内部矛盾，则只能用民主的方法，即说服教育的方法来解决。

### 3. 人民内部矛盾用民主的方法解决
> "凡属于思想性质的问题，凡属于人民内部的争论问题，只能用民主的方法去解决，只能用讨论的方法、批评的方法、说服教育的方法去解决。"

人民内部矛盾是根本利益一致基础上的矛盾，不能用强制的方法解决，只能用"团结——批评——团结"的方法解决。

### 4. 两类矛盾可以相互转化
> "在一般情况下，人民内部的矛盾不是对抗性的。但是如果处理得不适当，或者失去警觉，麻痹大意，也可能发生对抗。"

敌我矛盾和人民内部矛盾在一定条件下可以相互转化。处理不当，人民内部矛盾可能激化为对抗性矛盾；处理得当，一些对抗性矛盾也可以转化为非对抗性矛盾。

### 5. 正确处理人民内部矛盾是国家政治生活的主题
> "关于正确处理人民内部矛盾的问题，这是一个总题目。"

在社会主义社会，大规模的阶级斗争已经基本结束，正确处理人民内部矛盾成为国家政治生活的主题。

## 实战案例

- **整风运动（1957）**：通过"团结——批评——团结"的方法，解决党内的官僚主义、宗派主义和主观主义问题。
- **"百花齐放，百家争鸣"方针**：用民主的方法处理文化领域的人民内部矛盾，促进科学文化的发展。
- **民族政策**：用民族区域自治制度处理民族关系中的人民内部矛盾。

## 思想演变

| 时期 | 特征 |
|------|------|
| 延安时期（1942） | 整风运动中运用"团结——批评——团结"方法 |
| 建国初期（1949-1956） | 在实践中摸索处理不同性质矛盾的方法 |
| 形成期（1957） | 发表《关于正确处理人民内部矛盾的问题》，系统阐述 |
| 发展期（1957年后） | 在实践中不断丰富和发展 |

## 原话精选

1. "在我们的面前有两类社会矛盾，这就是敌我之间的矛盾和人民内部的矛盾。"
2. "凡属于思想性质的问题，凡属于人民内部的争论问题，只能用民主的方法去解决。"
3. "团结——批评——团结。"
4. "在一般情况下，人民内部的矛盾不是对抗性的。但是如果处理得不适当，也可能发生对抗。"
5. "百花齐放，百家争鸣，长期共存，互相监督。"
