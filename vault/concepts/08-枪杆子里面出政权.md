# 枪杆子里面出政权

## 定义与起源

"枪杆子里面出政权"是毛泽东在1927年八七会议上提出的著名论断。1927年，蒋介石发动四一二反革命政变，汪精卫发动七一五反革命政变，大革命失败。血的教训使毛泽东深刻认识到，在半殖民地半封建的中国，离开了武装斗争，就没有无产阶级和共产党的地位，就不能完成任何革命任务。这一论断成为中国共产党武装斗争路线的思想起点。

## 核心要义

### 1. 武装斗争是中国革命的主要形式
> "在中国，离开了武装斗争，就没有无产阶级的地位，就没有人民的地位，就没有共产党的地位，就没有革命的胜利。"

中国革命的特点和优点之一，就是以武装的革命反对武装的反革命。这是由中国半殖民地半封建社会的性质决定的。

### 2. 枪杆子里面出政权
> "须知政权是由枪杆子中取得的。"

革命的中心任务和最高形式是武装夺取政权，是战争解决问题。这个马克思列宁主义的革命原则是普遍的、正确的。

### 3. 党指挥枪，而决不允许枪指挥党
> "我们的原则是党指挥枪，而决不容许枪指挥党。"

武装力量必须绝对服从党的领导，这是人民军队的根本原则。军队是执行革命政治任务的工具，不是军阀的私人武装。

### 4. 人民军队的宗旨
> "紧紧地和中国人民站在一起，全心全意地为中国人民服务，就是这个军队的唯一的宗旨。"

人民军队来自人民、依靠人民、为了人民。这是人民军队区别于一切旧军队的根本标志。

### 5. 政治工作是军队的灵魂
> "政治工作是我军的生命线。"

在军队中建立政治工作制度，实行政治民主、经济民主、军事民主，保证军队始终保持正确的政治方向。

## 实战案例

- **八七会议（1927年8月）**：毛泽东在会上提出"政权是由枪杆子中取得的"论断，纠正了陈独秀右倾投降主义错误。
- **秋收起义（1927年9月）**：毛泽东领导发动秋收起义，后率部上井冈山，开始了武装斗争的新阶段。
- **三湾改编（1927年9月）**：确立"支部建在连上"的原则，从组织上保证了党对军队的绝对领导。

## 思想演变

| 时期 | 特征 |
|------|------|
| 大革命时期（1924-1927） | 忽视武装斗争，导致革命失败 |
| 八七会议（1927） | 提出"枪杆子里面出政权"论断 |
| 井冈山时期（1927-1929） | 建立新型人民军队，确立党指挥枪原则 |
| 古田会议（1929） | 系统阐述人民军队建设理论 |
| 延安时期（1935-1945） | 武装斗争理论全面成熟 |
