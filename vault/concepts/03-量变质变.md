# 量变质变

## 定义与起源

量变质变规律是唯物辩证法三大基本规律之一，毛泽东在《矛盾论》《实践论》及一系列著作中结合中国革命实际进行了深入阐发。毛泽东认为，事物的发展都是由量变到质变、再由质变到新的量变的过程。量变是渐进的、不显著的变化，质变是根本性的、飞跃式的变化。量变是质变的必要准备，质变是量变的必然结果。这一思想直接指导了中国革命的阶段性战略设计。

## 核心要义

### 1. 量变是质变的前提和准备
> "无论什么事物的运动都采取两种状态，相对地静止的状态和显著地变动的状态。两种状态的运动都是由事物内部包含的两个矛盾着的因素互相斗争所引起的。"

事物在量变阶段表现为相对稳定，但内部矛盾在不断积累，为质变创造条件。

### 2. 质变是量变的必然结果
> "事物总是要由量变进到质变的。"

当量的积累达到一定程度，超过一定的"度"，就会引起质的飞跃，事物发生根本性质的变化。

### 3. 革命的阶段性
> "我们是革命转变论者，不是托洛茨基主义的'不断革命'论者。我们主张经过民主共和国的必要的阶段，到达社会主义。"

中国革命必须分阶段进行，不能跳过必要的量变阶段直接进入质变。新民主主义革命和社会主义革命是两个相互衔接又性质不同的阶段。

### 4. 部分质变
> "在总的量变过程中有许多部分的质变。"

在根本质变发生之前，事物会经历若干部分质变，这些部分质变推动事物逐步走向根本质变。

### 5. 把握时机，促成飞跃
> "当着某一件事情（任何事情都是一样）要做，但是还没有方针、方法、计划或政策的时候，确定方针、方法、计划或政策，也就是主要的决定的东西。"

在量变积累到一定程度时，必须善于把握时机，果断促成质的飞跃，否则就会犯右倾保守的错误。

## 实战案例

- **新民主主义革命分两步走**：先完成反帝反封建的民主革命（量变积累），再转入社会主义革命（质变飞跃），不能"毕其功于一役"。
- **持久战三阶段**：战略防御（量变积累）、战略相持（量变深化）、战略反攻（质变飞跃），体现了量变到质变的过程。
- **从根据地到全国胜利**：从井冈山一小块根据地开始，逐步扩大，经过二十多年的量变积累，最终实现全国解放的质变。

## 思想演变

| 时期 | 特征 |
|------|------|
| 土地革命时期 | 在实践中摸索革命的阶段性 |
| 抗战时期 | 持久战理论体现量变质变规律 |
| 建国前夕 | 七届二中全会明确革命转变的条件和时机 |
| 社会主义时期 | 提出社会主义社会的"部分质变"理论 |

## 原话精选

1. "事物总是要由量变进到质变的。"
2. "我们是革命转变论者，不是托洛茨基主义的'不断革命'论者。"
3. "在总的量变过程中有许多部分的质变。"
4. "饭只能一口一口地吃，仗只能一仗一仗地打，敌人只能一部分一部分地消灭。"
5. "不可以无根据地胡思乱想，不可以超越客观情况所许可的条件去计划自己的行动。"
